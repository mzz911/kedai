1 Pilih Barang

Pilih Category, taip untuk tapis, tekan barang tu terus pilih. List dah sort ikut SKU menaik, lepas tu Abjad.

🔍
Tunjuk semua barang. Pilih Category / taip untuk tapis.
Auto A4 Landscape - besar penuh A4. Dalam 4Barcode biar je A4 / 100%.
Scan kat Loyverse untuk test

2 Senarai Barang

Sama style macam No 1 - pilih Category, taip untuk tapis, scroll dalam kotak tu je. Tekan Edit untuk tukar barang tu.

🔍
Tunjuk semua barang. Taip untuk tapis, atau pilih Category kat atas.
Senarai Barang Kau (0)
🔢 Sort: SKU menaik (00122 → 00999) → lepas tu Abjad (A → Z)

Senarai ditutup untuk senang scroll. Tekan Buka balik kalau nak tengok senarai.

3 Tambah Barang

Tambah barang baru, atau Edit barang yang kau tekan kat No 2 tadi. Auto simpan dalam phone. Nama boleh sama, SKU tak boleh sama.

Taip nama category baru yang belum ada dalam list. Nanti dia akan masuk dalam list Category untuk barang lain pulak.
Pilih category yang dah ada. Kalau takde, pilih "➕ Category Baru..." kat bawah list tu.
Kalau SKU yang kau taip tu dah ada orang pakai, dia akan bagitau nama barang tu + cadangkan PLU kosong yang lain. Tekan je nombor hijau tu untuk guna.
Ni untuk bezakan barang yang last 5 digit sama macam kes 00027 tu. Kalau kosong, dia akan guna SKU 5 digit tu je.

4 Import dan Export

Import dari Loyverse, atau Export senarai kau jadi CSV style Loyverse untuk backup / buka kat Excel.

📤 Import - Upload List dari Loyverse

Export CSV kat Loyverse > Items > Export, lepas tu upload kat sini. Category dari Loyverse akan ikut sekali.

Parent Y = ambik parent + SEMUA variant. Nama variant dari option 1 value / option 2 value / option 3 value. Kalau last 5 digit sama, dia tak timpa lagi - dia akan bagi PLU baru.
📥 Export - List Item Style Loyverse

Download senarai barang kau sekarang jadi CSV style Loyverse. Boleh buka kat Excel, boleh backup, boleh upload balik kat sini.

Format: Handle, SKU, Name, Category, Description, Sold by weight, Price, Option 1 Name, Option 1 Value
Variant akan jadi baris ke-2, ke-3... macam Loyverse - Name kosong, Option 1 Value = nama variant.
